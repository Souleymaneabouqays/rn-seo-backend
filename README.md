# Riviera Nuisibles — SEO Cockpit

Reconstruction propre du cockpit SEO.

## V1
- Next.js + TypeScript
- Dashboard sans fausses métriques
- Architecture prévue pour WordPress, Search Console, GA4 et fournisseurs SEO
- Déploiement Vercel

## Démarrage
```bash
npm install
npm run dev
```

Les secrets OAuth/API ne doivent jamais être commités dans GitHub. Ils seront ajoutés comme variables d'environnement Vercel.
